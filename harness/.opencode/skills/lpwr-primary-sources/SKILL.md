# Primary Sources

Countermeasure for the mislead trap (following bad advice): treat generated
code with zero trust; verify against sources that own the answer, plus
isolated execution tests where a claim is behavioral.

- Allowed: official docs, source code, specs, first-party APIs. Not allowed:
  blogs, tutorials, model say-so.
- Every non-trivial claim carries a source. The host command writes the cited
  memo; this skill governs which sources count and the citation bar.
