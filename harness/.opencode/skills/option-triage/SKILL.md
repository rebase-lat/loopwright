# Option Triage

Countermeasure for the forming trap (right question, wrong approach): ask for 3 distinct solution patterns and compare trade-offs _before_ committing to implementation.

- Seat 1 (neutral): plain restatement, no view. Seat 2 (deep expert): domain truth, what should happen. Seat 3 (applied judge): testability, what would convince me.
- Present patterns with cost, risk and reversibility. The human picks one — triage never self-selects.
